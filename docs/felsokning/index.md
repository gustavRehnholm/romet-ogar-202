# Felsökning

Här samlas felsökning av problem och symptom på Romet Ogar 202.

Börja med det symptom som bäst stämmer med problemet och kontrollera de enklaste möjliga orsakerna först.

## Motor

### [Onormala motorljud](motorljud.md)

Felsökning av exempelvis:

* tickande ljud från topplocket
* rasslande eller skramlande ljud
* misstänkt kamkedja eller kamkedjespännare
* andra nytillkomna mekaniska motorljud

## Grundprincip vid felsökning

1. Identifiera symptomen så tydligt som möjligt.
2. Kontrollera enkla och synliga orsaker först.
3. Ändra eller justera helst bara en sak åt gången.
4. Kontrollera om förändringen påverkade problemet.
5. Dokumentera vad som har kontrollerats och vilka resultat du fått.

Undvik att byta flera delar samtidigt utan att först försöka identifiera orsaken. Det gör det svårare att veta vad felet faktiskt berodde på.
