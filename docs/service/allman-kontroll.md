# Allmän kontroll

Den allmänna kontrollen görs för att upptäcka lösa, skadade eller slitna delar som inte täcks av någon mer specifik servicepunkt.

## Stöd

Kontrollera mittstödet efter:

* sprickor, deformation eller kraftig rost
* onormalt glapp i infästningen
* lösa eller saknade skruvar, muttrar eller andra infästningar
* skadad eller lös fjäder
* skador på stödets anliggningsytor mot marken

Fäll stödet upp och ned några gånger och kontrollera att:

* det rör sig utan att kärva
* det stannar korrekt i uppfällt läge
* fjädern drar tillbaka och håller stödet ordentligt
* stödet inte hänger ned eller kan röra sig onormalt under körning

Smörj stödets ledpunkt vid behov med lämpligt smörjmedel.

## Bultförband och infästningar

Gå visuellt över mopeden och leta efter lösa eller saknade skruvar, muttrar och andra infästningar.

Kontrollera särskilt områden som utsätts för vibrationer eller belastning, exempelvis:

* motorinfästningar
* avgassystemets infästningar
* fotpinnar och reglage
* styre och reglage
* stödet
* stötdämparnas infästningar
* pakethållare
* skärmar och kåpor
* registreringsskylt och hållare

Kontrollera även efter:

* skruvar eller muttrar som verkar ha börjat skruva ur sig
* sprickor eller deformation runt infästningar
* saknade brickor, sprintar eller andra låsningar
* skavmärken som kan tyda på att en del har rört sig

!!! warning "Åtdragning"
Dra inte åt alla bultar extra hårt som en rutinåtgärd.

```
Om ett förband är löst bör rätt åtdragningsmoment och eventuell låsningsmetod kontrolleras innan det dras åt. För hård åtdragning kan skada gängor, infästningar eller komponenter.
```

## Efter service

När övriga servicearbeten är färdiga:

1. Kontrollera att demonterade delar har återmonterats.
2. Kontrollera att verktyg eller lösa delar inte har lämnats kvar på mopeden.
3. Kontrollera visuellt efter läckage.
4. Kontrollera att vajrar, slangar och kablar ligger korrekt.
5. Kontrollera att inga delar tar i hjul, kedja, avgassystem eller andra rörliga eller heta komponenter.
6. Kontrollera att stöd och övriga reglage fungerar normalt.

Om något har demonterats eller justerats bör berörda infästningar kontrolleras en extra gång innan provkörning.
