# Serviceintervall

Serviceintervall för **Romet Ogar 202, årsmodell 2022**.

## Ordinarie service

| Service        | Intervall                    |
| -------------- | ---------------------------- |
| Första service | 300 km eller 3 månader       |
| Andra service  | 1500 km eller 12 månader     |
| Tredje service | 3000 km eller 24 månader     |
| Därefter       | Var 1500 km eller 12 månader |

Det som inträffar först av körsträcka och tid används.

## Löpande underhåll

Vissa kontroller och underhållspunkter bör utföras oftare än den ordinarie servicen.

| Servicepunkt                    | Intervall                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------ |
| [Motorolja](motorolja.md)       | Kontrollera oljenivån före körning                                                   |
| [Kedja](kedja.md)               | Rengör från smuts och grus ungefär var 14:e dag och håll kedjan smord                |
| [Hjulkontroll](hjulkontroll.md) | Kontrollera däcktrycket regelbundet, lämpligen vid varje tankning                    |
| Tvätt                           | Ungefär en gång per månad, oftare vid smutsiga förhållanden                          |
| Batteri                         | Underhållsladda vid behov, normalt 1–2 gånger per år och oftare vid liten användning |

Se respektive servicesida för mer information om hur kontrollen eller arbetet utförs.

Se [Manualer och källor](../mopeden/manualer-och-kallor.md) för dokumentationen som ligger till grund för serviceintervallen.
